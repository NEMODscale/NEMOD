Privacy Policy

This Pinterest automation tool does not collect, store, or share any personal data from users.

What This Tool Does

  • Takes an Amazon product URL provided by the user.
  • Scrapes public product info (title and image).
  • Uses the Pinterest API to publish a Pin with the user’s own account credentials.

Data Usage

All actions are performed in real-time and temporarily in memory. No information is stored or logged permanently. The only API keys involved are the ones the user manually provides and stores locally in environment variables.

Third-Party APIs

This tool uses:

  • Amazon: for public product data (non-authenticated)
  • OpenAI: for generating pin descriptions (title + text only)
  • Pinterest: for publishing pins using your token
